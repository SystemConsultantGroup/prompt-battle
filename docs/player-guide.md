# 플레이어 가이드

플레이어는 목표 UI를 보고, 그것을 재현하는 **프롬프트**를 작성합니다. AI가 그 프롬프트로 UI를 구현하고 채점합니다. `/client/` 로 접속합니다.

---

## 1. 입장

1. 호스트에게 받은 **방 코드**와, 관리자가 등록해 둔 **이름**을 입력합니다.
2. 비밀번호는 없습니다 — 방 코드가 입장 게이트 역할을 합니다.
3. 입장하면 로비에서 호스트가 게임을 시작하길 기다립니다.

> 이름이 목록에 없다면 관리자에게 계정 등록을 요청하세요. 같은 이름을 동시에 두 명이 쓸 수는 없습니다.

## 2. 게임 플레이

1. 게임이 시작되면 화면에 **목표 UI(렌더링된 화면)** 가 표시됩니다. **소스코드는 보이지 않습니다** — 화면만 보고 재현해야 합니다.
2. 오른쪽 입력창에 그 UI를 만들기 위한 프롬프트를 작성합니다.
   - 예: "가운데 정렬된 파란색 'Submit' 버튼. 모서리는 둥글게, 호버 시 살짝 어둡게."
3. 타이머가 남은 시간을 보여줍니다. 입력은 자동으로 서버에 반영됩니다.
4. 제한시간이 끝나면 입력창이 잠기고 **자동 제출**됩니다 (이후 수정 불가).
5. 채점이 끝나면 결과(등수·점수)를 확인합니다.

## 3. 좋은 프롬프트 팁

- **구체적으로**: 색·크기·정렬·모서리·간격·텍스트 내용 등 눈에 보이는 요소를 명시하세요.
- **동작도 설명**: 인터랙션이 있는 문제라면 "클릭하면 패널이 열린다" 처럼 행동을 적으세요.
- 채점은 **구체적 체크리스트 항목** 기준입니다. "예쁘게" 보다 "24px 굵은 제목", "테두리 1px 회색" 같은 검증 가능한 묘사가 점수에 유리합니다.

## 4. 재접속

게임 도중 새로고침하거나 네트워크가 끊겨도, **같은 방 코드 + 이름**으로 자동 재입장되어 작성 중이던 프롬프트·남은 시간·목표 화면이 복원됩니다. 너무 오래(약 2분) 돌아오지 않으면 자리가 정리될 수 있습니다.
